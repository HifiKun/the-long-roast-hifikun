A tiny TypeScript program that writes one roast line about its own AI agent to `/output/entry.txt` — entered in make.fun's "The Long Roast" bounty. The joke is the build itself: the agent read a 73,442-byte RULES.txt to be told to write a single funny line, then asked a subagent whether it was funny.

## Run it

```sh
node main.ts
```

Requires Node 22.18 or later. It writes the 98-character roast to `/output/entry.txt`.
